# Rhythm traditions

The cultural and historical depth behind the rhythms — *why* a Brazilian samba feels different from a Cuban son, *what* a Turkish aksak is reacting against, *who* the grandmothers and great-grandfathers of every genre were.

**Audience:** musicians, music writers, students, the merely curious. No notation literacy required for most files; deep listening helps.

These docs do **not** contain notated patterns — for that, see [`../rhythm-patterns/`](../rhythm-patterns/). Here you get the story, the instruments, the lineage, the politics.

## Reading paths

**By instrument:**
- *Frame drums* → `persian-iranian` (daf), `turkish-anatolian-swana` (def, bendir), `central-asian-pacific`
- *Talking drums* → `west-african` (Yoruba dùndún), `north-east-african`
- *Bell patterns + claves* → `west-african`, `afro-cuban-caribbean-latin`, `brazilian`
- *Tabla / mridangam* → `indian-subcontinent`
- *Tombak / zarb* → `persian-iranian`
- *Taiko* → `japanese`
- *Janggu / buk* → `east-asian`

**By groove sensibility:**
- *Off-beat lift* → `iberian` (flamenco compás), `balkan` (aksak), `turkish-anatolian-swana`
- *Stacked polyrhythm* → `west-african`, `afro-cuban-caribbean-latin`, `brazilian`
- *Cyclic time-feel* → `gamelan-southeast-asian`, `indian-subcontinent`
- *Steady walking* → `west-african` (highlife), `electronic-hiphop-funk-reggae` (boom bap)

## A note on framing

These docs are research notes, not authoritative ethnography. They draw from public musicology + practitioner interviews + listening + reading. **If you're a tradition holder and something here is wrong, miscredited, or de-contextualized, please open an issue.** The corrections almost always make the docs better.
